📖 Sobre o projeto

O HollowMovie é uma aplicação web voltada para descoberta e pesquisa de filmes e séries.

A plataforma permite pesquisar títulos e refinar os resultados utilizando diferentes filtros, proporcionando uma experiência simples e intuitiva para encontrar conteúdos para assistir.

O projeto foi desenvolvido como uma forma de praticar desenvolvimento Front-End, trabalhando com estruturação de páginas, estilização, JavaScript, consumo de dados e criação de uma interface interativa.

✨ Funcionalidades

• 🔎 Pesquisa por filmes
• 🎬 Navegação entre filmes e séries
• 🏷️ Filtro por gênero
• 📅 Filtro por ano
• ⭐ Filtro por nota mínima
• 🌎 Filtro por país
• 📄 Página de detalhes dos títulos
• ⏮️⏭️ Navegação entre resultados
• 📱 Interface responsiva
• 🎨 Interface temática inspirada no universo cinematográfico

🛠️ Tecnologias

• HTML5
• CSS3
• JavaScript
• API de filmes
• Netlify — hospedagem e deploy

🚀 Executando localmente

Clone o repositório

```bash
git clone https://github.com/Feulips/HollowMovie.git
```

Entre na pasta

```bash
cd HollowMovie
```

Execute

Por ser uma aplicação baseada em HTML, CSS e JavaScript, você pode abrir o index.html diretamente no navegador.

Durante o desenvolvimento, recomenda-se utilizar o Live Server do VS Code para facilitar a execução e atualização da aplicação.

🎯 Objetivos do projeto

O desenvolvimento do HollowMovie teve como principais objetivos:

• Praticar desenvolvimento Front-End
• Trabalhar com JavaScript e manipulação do DOM
• Criar interfaces responsivas
• Trabalhar com APIs e dados de filmes
• Desenvolver sistemas de pesquisa e filtros
• Organizar um projeto web de forma modular
• Praticar deploy e hospedagem de aplicações
